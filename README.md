# README — Jogo de Investigação Criminal

## Sobre o Projeto

O **Jogo de Investigação Criminal** é um sistema interativo desenvolvido em Python, onde o jogador assume o papel de um detetive responsável por resolver um crime.

Durante o jogo, o usuário pode:

* Investigar locais
* Coletar pistas
* Interrogar suspeitos
* Fazer acusações
* Descobrir o verdadeiro culpado

O projeto foi criado com foco no aprendizado de conceitos fundamentais da programação em Python.

---

#  Tecnologias Utilizadas

* Python 3
* Biblioteca padrão `time`

---

#  Conceitos Aplicados

O projeto utiliza:

* Variáveis
* Estruturas condicionais (`if`, `elif`, `else`)
* Laços de repetição (`while`)
* Funções (`def`)
* Listas
* Dicionários
* Tratamento de erros (`try/except`)
* Modularização do código

---

#  Como Executar o Programa

## 1. Instale o Python

Baixe e instale o Python pelo site oficial:

[Python Oficial](https://www.python.org/downloads/?utm_source=chatgpt.com)

---

## 2. Baixe o arquivo do projeto

Salve o arquivo com o nome:

```text
jogodetetive.py
```

---

## 3. Abra o terminal na pasta do projeto

No Windows:

* Abra a pasta
* Clique com botão direito
* Selecione:

  * “Abrir no Terminal”
  * ou “Open in Command Prompt”

---

## 4. Execute o programa

Digite o comando:

```bash
python jogodetetive.py
```

ou:

```bash
python3 jogodetetive.py
```

---

#  Como Jogar

O jogador deverá:

1. Explorar os ambientes
2. Coletar pistas
3. Interrogar suspeitos
4. Analisar as informações
5. Acusar o culpado correto
